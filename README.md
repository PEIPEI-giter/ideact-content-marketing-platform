# Ideact 内容营销后台

当前项目是 Ideact 内容营销后台的本地开发工程。已有内容生产、知识库问答、模型接入等基础能力；本次项目初始化只为“云手机发布”模块预留开发骨架，不实现业务功能、不接入真实阿里云、不写入真实凭证。

## 技术选型

- 前端：React + TypeScript + Vite。继续复用当前项目的单页后台结构和 `src/styles.css` 设计变量。
- 服务端：Node.js + Express + TypeScript。业务 API 继续放在 `server/`，云手机能力单独放入 `server/cloud-phone/`。
- 数据库：SQLite。第一阶段需要持久化设备、连接租约、任务、任务事件和人工接管状态；当前仅预留 Repository 目录，不创建表和假数据。
- Provider：先使用 `MockCloudPhoneProvider` 跑通本地流程，后续再新增阿里云 Provider，把 OpenAPI 调用限制在 Provider 层。
- 测试：Vitest。后续云手机测试放在 `tests/cloud-phone/`，自动化测试只使用 Mock Provider，不调用真实阿里云。

## 第一阶段范围

第一阶段只做云手机控制 MVP：

- 设备查看
- 云手机连接
- 画面操控
- 自然语言任务
- 任务状态
- 暂停和人工接管

不在第一阶段实现私域自动回复、真实发布队列、素材传入、公众号排版或内容审核。

## 配置说明

复制 `.env.example` 为 `.env` 后再填写本地配置。`.env.example` 只能保留空占位，不能写真实 AccessKey、Token、实例 ID 或桥接密钥。

云手机真实接入前需要准备：

- 阿里云 RAM AccessKey
- 云手机实例 ID
- 正确地域和 Endpoint
- 无影 Web SDK 文件

这些信息只允许由服务端读取；前端不得读取云厂商密钥。

## 发布内容

在“云手机发布 → 发布内容”中，选择内容生产流水线的创作记录、已生成渠道文案和配图，再选择云手机及立即/定时发布。预览审核确认后，服务端将任务保存到 `data/publishing-jobs.json`。此文件不进入版本控制。服务端运行期间每 5 秒检查到期任务；停机期间不会准时执行，重启后会处理到期任务。重启时处于准备阶段的任务会转为待人工核验，避免重复发帖。

生图结果会保存在本机 `public/generated-images/`，创作记录关联该本地文件。带图发布无需购买公网服务器或配置 HTTPS 图片地址：服务端通过阿里云云手机远程命令分块传图，校验文件一致后才启动发布任务。传输可能需要数分钟，失败会保留本机原图并停止发布；云手机 AccessKey 需有 `RunSyncCommand` 权限。创作记录目前保存在当前浏览器本地存储，清理浏览器数据会丢失记录索引，但不会删除本机图片文件。发布由 `RunAgentTask` 执行，状态由 `DescribeAgentTask` 查询；不做自动重试。任务完成后仍需运营人员在对应平台账号核实，人工确认后记录才显示“已确认发布”。

发布记录在本地服务端保存；创作记录目前仍由当前浏览器的 `localStorage` 保存，换浏览器或清理缓存后无法读取旧创作记录。当前工程没有用户鉴权和多租户隔离，发布接口仅用于受控的本地开发环境，不应直接暴露到公网。真实发布前，请确认云手机目标账号已登录、具有发布权限，并先用非正式内容手动验收。

## 私域获客 / 私信聚合

私域运营页可按设备和小红书账号筛选会话。首次使用时，在云手机中确认当前登录的小红书账号，然后在页面左侧手动关联设备与账号名称；多台设备可在服务端 `.env` 的 `ALIYUN_CLOUD_PHONE_INSTANCE_IDS` 中用英文逗号分隔配置。切换手机中的账号后必须重新关联，系统不会读取密码、Cookie 或 Token，也不会猜测账号身份。

服务端每 30 秒通过阿里云只读远程命令读取 Android 系统通知；只接受小红书包名和严格的“某某 私信你”标题。关联后的第一次扫描只建立旧通知基线，不创建旧线索；后续通知建立待同步会话，但通知摘要不是完整聊天消息。打开该客户的小红书聊天页后，在工作台点击“同步当前聊天页”，服务端通过 `uiautomator` 读取当前页面控件树，核对客户名称和输入框后才保存可识别的消息。该过程不调用自然语言 Agent。没有通知时也可填写客户名称手动同步；重复同步相同页面不重复保存。账号发出的消息如无法证明由人工或 AI 发送，标为“来源未核验”。

账号、线索和消息保存在服务端 `data/private-inbox.json`，刷新页面仍可读取。当前是本地开发模式，没有多用户登录和权限隔离；包含客户私信的数据不得将 API 或 Vite 代理直接暴露到公网。不同小红书版本的通知格式、聊天页控件结构可能改变，真实设备联调前不能声称采集已通过；失败会显示原因，且不写入猜测的消息。
