# Ideact 内容营销后台

当前项目是 Ideact 内容营销后台，已包含运营概览、知识库问答、社媒内容生产、云手机操控与发布、私信聚合以及文本/图片模型接入。真实凭证只从服务端 `.env` 读取，不进入前端构建或版本库。

生产站点：<https://121.41.88.142/>。部署架构、数据文件、配置和团队验收步骤见 [`docs/生产部署与团队测试说明.md`](docs/生产部署与团队测试说明.md)。

## 运营概览

一级导航中的“运营概览”汇总当前系统的真实运营数据：知识库配置、创作对象、各对象的选题与简报、发布任务、渠道以及私域账号。点击“刷新数据”会重新读取服务端内容工作区和其他业务数据。

创作对象、选题、简报、平台文案、图片结果和创作记录由服务端内容工作区持久保存，浏览器仅保留同步缓存；首次升级会自动迁移当前浏览器已有数据。知识库、发布记录和私域账号从服务端接口读取。服务端某一项暂时不可用时，概览保留其他可用统计并单独显示失败原因，不使用演示数字补齐。

## 技术选型

- 前端：React + TypeScript + Vite。继续复用当前项目的单页后台结构和 `src/styles.css` 设计变量。
- 服务端：Node.js + Express + TypeScript。业务 API 继续放在 `server/`，云手机能力单独放入 `server/cloud-phone/`。
- 数据保存：发布记录、私信记录和内容生产资产均使用服务端 JSON 文件原子写入；`localStorage` 仅作为当前浏览器的同步缓存。
- Provider：阿里云云手机 OpenAPI 调用集中在 Provider 层；自动化测试使用模拟响应，不创建真实付费任务。
- 测试：Vitest。自动化测试不调用真实模型、真实发布或付费 Agent 任务。

## 配置说明

复制 `.env.example` 为 `.env` 后再填写本地配置。`.env.example` 只能保留空占位，不能写真实 AccessKey、Token、实例 ID 或桥接密钥。

后台使用单用户账号密码登录。请在服务端 `.env` 中填写 `MVP_USER_EMAIL` 和 `MVP_USER_PASSWORD`；会话只保存在服务端内存中，Cookie 为 `HttpOnly` 且默认 24 小时有效，服务重启后需要重新登录。公网启用 HTTPS 后将 `MVP_COOKIE_SECURE` 设置为 `true`。登录失败连续达到 5 次后，同一来源会暂停登录 15 分钟。

云手机真实接入前需要准备：

- 阿里云 RAM AccessKey
- 云手机实例 ID
- 正确地域和 Endpoint
- 无影 Web SDK 文件

这些信息只允许由服务端读取；前端不得读取云厂商密钥。

## 发布内容

在“云手机发布 → 发布内容”中，选择内容生产流水线的创作记录、已生成渠道文案和配图，再选择云手机及立即/定时发布。预览审核确认后，服务端将任务保存到 `data/publishing-jobs.json`。此文件不进入版本控制。服务端运行期间每 5 秒检查到期任务；停机期间不会准时执行，重启后会处理到期任务。重启时处于准备阶段的任务会转为待人工核验，避免重复发帖。

生图结果会保存在本机 `public/generated-images/`，创作记录同时保留千问返回的临时 HTTPS 源地址。带图发布不需要购买公网服务器：服务端通过阿里云 `SendFile` 的 `DOWNLOAD_URL` 模式让云手机整图下载，最多 3 张并行传输，不再用远程命令拆块。千问源地址过期时任务会停止并提示重新生成图片，本机原图仍会保留。创作记录索引由服务端内容工作区保存，清理浏览器缓存后会在下次登录时恢复。发布由 `RunAgentTask` 执行，状态由 `DescribeAgentTask` 查询；不做自动重试。任务完成后仍需运营人员在对应平台账号核实，人工确认后记录才显示“已确认发布”。

发布记录和创作记录均在本地服务端保存，换浏览器或清理缓存后可在登录时恢复。默认内容工作区文件为 `data/content-workspace.json`，可用 `CONTENT_WORKSPACE_PATH` 调整位置。当前工程已提供单用户登录，但没有多租户和角色权限；正式公网使用前仍需启用 HTTPS、使用强密码并限制服务器安全组。真实发布前，请确认云手机目标账号已登录、具有发布权限，并先用非正式内容手动验收。

## 私域获客 / 私信聚合

私域运营页可按设备和小红书账号筛选会话。首次使用时，在云手机中确认当前登录的小红书账号，然后在页面左侧手动关联设备与账号名称；多台设备可在服务端 `.env` 的 `ALIYUN_CLOUD_PHONE_INSTANCE_IDS` 中用英文逗号分隔配置。切换手机中的账号后必须重新关联，系统不会读取密码、Cookie 或 Token，也不会猜测账号身份。

服务端每 30 秒通过阿里云只读远程命令读取 Android 系统通知；只接受小红书包名和严格的“某某 私信你”标题。关联后的第一次扫描只建立旧通知基线，不创建旧线索；后续通知建立待同步会话，但通知摘要不是完整聊天消息。打开该客户的小红书聊天页后，在工作台点击“同步当前聊天页”，服务端通过 `uiautomator` 读取当前页面控件树，核对客户名称和输入框后才保存可识别的消息。该过程不调用自然语言 Agent。没有通知时也可填写客户名称手动同步；重复同步相同页面不重复保存。账号发出的消息如无法证明由人工或 AI 发送，标为“来源未核验”。

账号、线索和消息保存在服务端 `data/private-inbox.json`，刷新页面仍可读取。接口需要先登录后台；聊天同步会自动过滤已读/已阅、时间、账号名称等控件文字，并清理同批次重复内容。不同小红书版本的通知格式、聊天页控件结构可能改变，真实设备联调前不能声称采集已通过；失败会显示原因，且不写入猜测的消息。
